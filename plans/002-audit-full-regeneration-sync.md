## Why this matters

`workflows/*.json` are generated by `src/build_workflows.py` and committed;
they are what gets imported into n8n. `scripts/audit-invariants.py` check 9
("workflows in sync with src/") only verifies that each node's `jsCode` and
SQL `query` string exists somewhere in `src/`. If someone edits anything else
in the generator — the agent system prompt `SYSTEM_MESSAGE`, a node's
`retryOnFail`, a model name, a wire — and forgets to rebuild, the audit still
says PASS and stale JSON is committed and imported. The fix: let the audit
regenerate every workflow **in memory** and compare it with what is on disk.
That requires the builders to return data instead of writing files.

## Steps

### Step 1: Split `WF.write` into `to_json()` + `write()`

In class `WF`:
- Add `to_json(self) -> str` containing everything `write` does today
  **except** the file write and the print: the validation asserts (including
  the plan-001 reference check if present), building `wf`, and
  `return json.dumps(wf, indent=2, ensure_ascii=False) + "\n"`.
- Change `write(self, filename)` to:
  ```python

      (OUT / filename).write_text(self.to_json(), encoding="utf-8", newline="\n")
      print(f"wrote workflows/{filename}: {len(self.nodes)} nodes")
  ```

**Verify**: `python3 src/build_workflows.py` → exit 0, then
`git status --short workflows/` → empty.

### Step 2: Make builders return `(filename, WF)` without writing

Change each of the four builders so the last line is
`return "<same filename>", w` instead of `w.write("<same filename>")`.
Filenames, unchanged: `workflow_speak.json`, `workflow_morning_briefing.json`,
`workflow_assistant.json`, `workflow_university_mail.json`.

Add a module-level function:
```python
BUILDERS = (build_speak, build_briefing, build_assistant, build_unimail)


def build_all():
    """{filename: WF} for every workflow. Pure: writes nothing."""
    return dict(b() for b in BUILDERS)
```
(`BUILDERS` must be defined after the four functions, e.g. just above
`build_skills` or above `__main__`.)

Update `__main__`:
```python
if __name__ == "__main__":
    OUT.mkdir(exist_ok=True)
    for filename, w in build_all().items():
        w.write(filename)
    build_skills()
    lint_expressions()
    print("expression lint OK")
```

**Verify**: `python3 src/build_workflows.py` → same 4 `wrote workflows/...`
lines as before (order may be speak, briefing, assistant, unimail), exit 0;
`git status --short workflows/` → empty.
