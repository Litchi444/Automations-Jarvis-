# Writing a lettre de motivation

## Before writing
- You need: the company, the position, and the offer's key requirements. If the user did not give the offer, ask for it, or at least the company and position, in one short question.
- Use only experience, skills and studies the user actually stated, earlier in this chat or now. Never invent a diploma, a job, a skill or a number. Leave a placeholder like [expérience] where something is missing, and say so after the draft.

## Format (French conventions)
- At most one page, about 250 to 350 words.
- Top: "Objet : Candidature au poste de [poste] ([stage / alternance / CDI], réf. [référence] if there is one)".
- Greeting: "Madame, Monsieur," or "Madame X," if the recruiter is named.
- Three paragraphs, the "vous, moi, nous" structure:
  1. Vous: why this company. Something specific about it (activity, project, values), not generic praise.
  2. Moi: 2 or 3 concrete points matching the offer's requirements, each backed by a fact (course, project, job, result).
  3. Nous: what the user will bring, the start date or rhythm (alternance), and a request for an interview.
- Closing: "Je vous prie d'agréer, Madame, Monsieur, l'expression de mes salutations distinguées." followed by the user's name.

## Tone
- Use vous. Confident and precise, no clichés ("dynamique et motivé", "je me permets de", "votre entreprise leader").
- Short sentences. Active voice. One idea per sentence.

## Output
- Plain text with line breaks, no markdown. Send it as a written (text) reply.
- After the letter, one line listing any placeholders the user must fill in.
