# Writing an email

## Before writing
- Work out who it is for, what the user wants from them, and any deadline. If the recipient or the goal is unclear, ask one short question instead of guessing.
- Write in the language the user asked for. If they did not say, use French for French recipients (university, French companies), otherwise the user's language.

## Structure
1. Subject line: "Objet : ..." in French, "Subject: ..." in English. Specific, under 8 words (e.g. "Objet : Demande de report du rendu du TP 3").
2. Greeting:
   - Professor: "Bonjour Madame X," / "Bonjour Monsieur X,". Use "Madame, Monsieur," if the name is unknown.
   - Administration: "Madame, Monsieur,".
   - English: "Dear Dr X," / "Dear Ms X,", or "Hello X," if informal.
3. First sentence: who the user is if the reader may not know (e.g. "étudiant en L2 Informatique, groupe TD 2"), then the request or the reason for writing.
4. Body: 2 to 4 short sentences. Facts, dates, course or file references. One request per email.
5. Closing that matches the ask:
   - French formal: "Je vous remercie par avance pour votre retour. Bien cordialement,"
   - French very formal (administration, cover letter): "Je vous prie d'agréer, Madame, Monsieur, l'expression de mes salutations distinguées."
   - English: "Thank you in advance. Best regards,"
6. Signature: the user's first and last name. Add the student number only if the recipient is the university administration and the user gave it.

## Tone
- Polite and direct. No excessive apologies, no flattery, no filler such as "j'espère que vous allez bien" unless the user wants it.
- Use vous in French unless the user says they use tu with this person.
- Never invent facts, dates, grades or excuses. Leave a placeholder like [date] when something is missing, and tell the user.

## Output
- Plain text with line breaks, no markdown. Send it as a written (text) reply so it can be copied.
- After the draft, one short line offering to adjust the tone or length.
- Jarvis cannot send emails: it only drafts them. The user sends the email themselves.
